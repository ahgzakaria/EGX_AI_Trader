# EGX AI Trader

AI-powered stock analysis platform for the Egyptian Stock Exchange (EGX).

## Features

- Technical Analysis
- Stock Scanner
- Support & Resistance
- Entry / Stop Loss / Targets
- BUY / WATCH / AVOID Signals
- Streamlit Dashboard

## Technologies

- Python
- Streamlit
- Plotly
- Pandas
- NumPy
- yfinance
- TA
- Scikit-learn
- XGBoost

## Run

```bash
pip install -r requirements.txt

streamlit run app.py
```
